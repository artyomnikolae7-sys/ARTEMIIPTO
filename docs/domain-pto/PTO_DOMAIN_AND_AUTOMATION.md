## 🔄 2. Жизненный Цикл Исполнительной Документации (ИД Pipeline)

Цикл подготовки ИД состоит из 6 строгих верификационных этапов:

```
[1. Чертёж РД] ──► [2. Спецификация СО] ──► [3. База ЭТМ / Поставка] ──► [4. Шахматка ВОР] ──► [5. Формирование АОСР] ──► [6. Сдача в Exon / МГСН]
```

1. **Анализ рабочей документации (РД):** Сверка планов прокладки кабельных трасс, стояков, лотков и спецификации оборудования (СО).
2. **Сопоставление с базой поставщиков (ЭТМ):** Привязка проектных позиций к каноническим артикулам кабельной продукции, проверка сертификатов соответствия и пожарных протоколов.
3. **Ведомость объемов работ («Шахматка ВОР»):** Разложение объемов по секциям, этажам, помещениям и захваткам. Фиксация разниц «проект / факт».
4. **Формирование комплекта АОСР:** Автоматическая генерация бланков актов скрытых работ по форме РД-11-02-2006, прикрепление схем геодезической съемки и паспортов.
5. **Загрузка и подписание в Exon:** Пакетный ввод объемов через DOM-скрипты, подписание усиленной квалифицированной электронной подписью (ЭЦП).
6. **Закрытие форм КС-2 / КС-3:** Финансовое закрытие выполненных объемов без замечаний технического надзора.

## ⚡ 3. Семь Прикладных Инженерных Кейсов Автоматизации

### Кейс 01. Расчётная таблица земляных работ и выработки бригад
- **Проблема:** Разрозненный ручной учет выработки рабочих по 17 объектам, потеря контроля времени, кассовые разрывы на субподряде.
- **Инструменты:** Excel, Power Query, сводные таблицы с параметрическим автообновлением.
- **Результат:** Прозрачная сквозная система контроля выработки по каждому объекту, снижение ошибок на сверках до 0%.

### Кейс 02. Генератор комплекта ИД по ОЗДС (ускорение до 6–8 часов)
- **Проблема:** Ручная сборка повторяющегося пакета ИД по охранно-защитным дератизационным системам занимала 3–4 рабочих дня из-за сбоев нумерации и дублирования паспортов.
- **Инструменты:** Excel VBA, шаблонизатор АОСР, логика динамического реестра с автопересчетом страниц и генерацией итогового PDF в 1 клик.
- **Результат:** Срок подготовки комплекта сокращен с 3–4 дней до 6–8 часов при 100% прохождении технадзора.

### Кейс 03. Сводная ведомость объемов внутренних сетей (факт / проект)
- **Проблема:** Сложность выявления локальных перерасходов и недоборов кабельной продукции по этажам и стоякам.
- **Инструменты:** Excel Power Query, многоуровневая структура «система → секция → этаж → проектный объем → факт».
- **Результат:** Моментальный визуальный контроль отклонений объемов до отправки ИД на проверку.

### Кейс 04. Прототип табеля учета времени и дашборд Power BI
- **Проблема:** Руководство не видело узких мест в распределении времени инженеров ПТО по объектам и системам.
- **Инструменты:** Excel Data Model, Power BI Desktop, DAX-метрики, интерактивные срезы.
- **Результат:** Наглядная управленческая аналитика скорости закрытия разделов и загрузки сотрудников.

### Кейс 05. Параметрический расчет телефонной канализации НСС + связка с AutoCAD
- **Проблема:** При малейшем сдвиге трассы наружных сетей инженеру приходилось вручную пересчитывать все объемы грунта, песчаной подушки, длины труб и заново чертить профили.
- **Инструменты:** Excel-формулы параметров траншеи + передача данных в блоки и поля AutoCAD.
- **Результат:** Мгновенный каскадный пересчет объемов и актуализация чертежей без повторных ручных вычислений.

### Кейс 06. Автоматизация пакетного ввода объемов работ в Exon (JS)
- **Проблема:** Ввод сотен позиций в формы веб-интерфейса Exon вручную отнимал часы монотонного труда и приводил к опечаткам в объемах.
- **Инструменты:** JavaScript DOM-automation, XML/Excel парсер структуры данных.
- **Результат:** Автоматическое заполнение 450+ строк формы за 3 минуты с верификацией полей и контролем применения.

### Кейс 07. AXIS AI: Оцифровка и валидация однолинейных схем (ЭОМ)
- **Проблема:** Ручной перенос номиналов автоматов, мощностей, токов и сечений кабелей из графических однолинейных схем ВРУ/РШУ в кабельные журналы.
- **Инструменты:** OpenDataLoader PDF Engine (JDK 21), LLM Chain-of-Thought, формулы кросс-валидации ($I_{\text{ном}} \ge I_{\text{р}}$, $P_{\text{расч}} = P_{\text{ном}} \times K_{\text{с}}$).
- **Результат:** Полностью автоматизированная оцифровка схем с исключением человеческого фактора.
