# 🎨 Руководство по Дизайн-Системе (Design System & Guidelines)

> Основано на стандартах **`frontend-design`**, **`impeccable` (Neo-Kinpaku & ElevenLabs)** и **`beUI`**.  
> Документ регламентирует визуальный язык, цветовые токены OKLCH, сетки, микро-взаимодействия и правила верстки.

---

## 💎 1. Философия и Принципы Дизайна

### Главное правило: Инженерный характер без шаблонности
Интерфейс строится вокруг реального мира инженера ПТО: технические чертежи, ведомости объемов, кабельные журналы, системы связи, точность формул и строгая структура. 

1. **Hero — это Тезис, а не лозунг:**  
   Первый экран четко объясняет специализацию: трансформация строительной документации в алгоритмизированные процессы и верифицированные данные.
2. **Структура несет смысл:**  
   Разделители, бейджи, временные шкалы и таблицы отражают реальную последовательность строительного контроля (РД → Спецификация → Поставка/ЭТМ → Монтаж → АОСР → ИД в Exon → Согласование МГСН).
3. **Отказ от клише AI-дизайна:**  
   Никаких случайных фиолетовых размытий или бессмысленных декораций. Каждый цветной акцент (красный/оранжевый для ПТО, циан для терминала, золото для исполнительного слоя) привязан к функциональному контексту.

## 🎨 2. Семантические Токены Цвета (OKLCH Color Palette)

Проект использует современный цветовой стандарт **OKLCH** в связке с **Tailwind CSS v4** для идеальной цветопередачи и соблюдения контрастности по WCAG AAA (минимальный контраст текста 7:1 к фону).

### 2.1. Основные темы интерфейса

#### A. Master Dark Theme (Основной инженерный режим)
```css
:root {
  --background: oklch(0.12 0.01 250);        /* Глубокий темный сланец #0b0c10 */
  --foreground: oklch(0.92 0.01 250);        /* Чистый читаемый светлый текст #c5c6c7 */
  --card: oklch(0.16 0.015 250 / 0.7);       /* Полупрозрачные стеклянные панели */
  --border: oklch(0.25 0.02 250 / 0.6);      /* Тонкие структурные границы */
  --primary: oklch(0.65 0.24 28);            /* Инженерный сигнальный красный/оранжевый */
  --accent: oklch(0.72 0.18 55);             /* Акцентный оранжевый для градиентов */
  --ring: oklch(0.75 0.15 195);              /* Циан/электрик для фокуса и меток */
  --success: oklch(0.70 0.17 150);           /* Изумрудный для статуса «Сдано / 100%» */
}
```

#### B. Neo-Kinpaku Theme (Режим v3 Executive Showcase)
```css
.theme-kinpaku {
  --lacquer-black: oklch(0.08 0.006 95);     /* Черный японский лак */
  --kinpaku-gold: oklch(0.84 0.19 80.46);    /* Сусальное золото #e5c158 */
  --verdigris-patina: oklch(0.70 0.12 188);  /* Патина / бирюза #4ecdc4 */
  --champagne: oklch(0.91 0 0);              /* Белый нейтральный заголовок */
  --dark-ink: oklch(0.14 0.018 95);          /* Текст поверх золотых кнопок */
}
```

#### C. Editorial Light Paper (Режим v4 Academic Monograph)
```css
.theme-paper {
  --paper-bg: oklch(0.97 0.012 95);          /* Теплая архивная бумага #faf7f2 */
  --paper-card: oklch(1.00 0 0);             /* Белая карточка с рамкой */
  --ink-primary: oklch(0.16 0.02 95);        /* Глубокие угольные чернила #1c1917 */
  --ink-muted: oklch(0.45 0.015 95);         /* Приглушенный текст пояснений */
  --terracotta: oklch(0.58 0.15 35);         /* Терракотовый акцент #c25e3d */
  --forest-green: oklch(0.42 0.14 145);      /* Строительный зеленый статус */
}
```

## 🔤 3. Шрифтовая Иерархия (Typography System)

В проекте используется гармоничная многоуровневая типографика:

| Семейство шрифтов | Роль в интерфейсе | Пример применения |
|---|---|---|
| **Space Grotesk / Geist Display** | Заголовки (H1, H2, H3) | Названия секций, главные титулы hero, цифры метрик |
| **Inter / Geist Sans** | Основной текст интерфейса | Описания кейсов, биография, отзывы, модальные окна |
| **IBM Plex Mono / Geist Mono** | Технические данные и код | Номера АОСР, артикулы ЭТМ, координаты, команды терминала |
| **Playfair Display / Serif** | Акцентные вставки и цитаты | Курсивные акценты в hero («документация», «данные») |

### Масштаб типографики (Type Scale)
- **Display 1 (Hero Title):** `text-4xl md:text-6xl lg:text-7xl font-bold tracking-tight`
- **Section Title (H2):** `text-3xl md:text-4xl font-bold tracking-tight`
- **Card Title (H3):** `text-xl md:text-2xl font-bold`
- **Body Regular:** `text-sm md:text-base leading-relaxed`
- **Technical Tag / Eyebrow:** `text-[10px] md:text-xs font-mono uppercase tracking-widest font-bold`

## 📐 4. Сетка, Карточки и Отступы (Layout & Spacing)

- **Максимальная ширина контейнера:** `max-w-[100rem]` (1600px) для дашбордов и широких экранов, `max-w-6xl` для текстовых секций.
- **Базовый вертикальный ритм:** `space-y-24` между глобальными блоками, `py-8 md:py-16` внутри секций.
- **Скругление углов (Border Radius):**
  - Кнопки и бейджи: `rounded-xl` (12px) или `rounded-full`
  - Карточки и панели: `rounded-2xl` (16px) до `rounded-3xl` (24px)
- **Glassmorphism:** `backdrop-blur-xl bg-white/[0.03] border border-white/10 shadow-2xl` с тонкими свечениями (`ambient-orb`).

---

## ⚡ 5. Анимации и Микро-взаимодействия (Motion Architecture)

- **Плавный скролл:** `lenis` с `lerp: 0.1` для естественной инерции страницы.
- **ScrollReveal:** появление секций с подъемом снизу (`opacity: 0, y: 30` → `opacity: 1, y: 0`) с задержкой по `viewport.once`.
- **Карточки объектов и кейсов:** плавное масштабирование при наведении (`hover:scale-[1.02]`), подсветка границы сигнальным цветом.
- **Метеоры и фоновые частицы:** фоновый Canvas/CSS (`Meteors`, `floating-grid`), не блокирующий поток рендеринга (GPU-ускорение).
- **Reduced Motion:** строгое соблюдение `prefers-reduced-motion: reduce` с отключением параллакса и непрерывных анимаций.
